# 일반 게시판 개발 내용 가이드

## 1. 프로젝트 개요
### 목표
- 사용자가 웹상에서 자유롭게 게시글을 작성, 열람, 수정, 삭제할 수 있는 일반 게시판 서비스 구축
- 직관적인 게시판 인터페이스와 실시간 검색, 페이징 처리를 결합하여 쾌적한 UX 제공
- 서버리스 백엔드 + 고품격 정적 프론트엔드 구조로 확장성과 비용 효율성 극대화

### 주요 요구사항
- 게시글 목록 조회 및 페이징 처리
- 키워드를 통한 게시글 검색 기능
- 게시글 상세 정보 보기
- 게시글 등록/수정/삭제 (CRUD)
- 서버리스 환경에서의 무장애 엣지 연동 보장

## 2. 기술 스택
- 프론트엔드: Vite + Vue 3 (Composition API) + TypeScript + Vanilla CSS
- 백엔드: Node.js ESM + Express (Vercel Serverless Functions)
- 데이터베이스: Turso Cloud DB + `@libsql/client/web` (HTTP REST 연동 전용 드라이버)
- 배포: Vercel
- 환경설정: `./doc/개발환경.md` 참조

## 3. 게시판 예제 구성
### 3-1. 프론트엔드 구성
- `src/pages/BoardList.vue`
  - 게시글 목록 조회, 페이징 네비게이션, 검색창 및 카테고리 필터 UI
- `src/components/BoardRow.vue`
  - 게시글 목록의 행(Row)을 렌더링하는 컴포넌트 (번호, 제목, 작성자, 작성일, 조회수)
- `src/pages/BoardDetail.vue`
  - 게시글 상세 보기 화면 및 수정/삭제 액션 버튼 배치
- `src/pages/BoardWrite.vue`
  - 게시글 등록 및 기존 글 수정 폼 화면 (유효성 검사 포함)

### 3-2. 백엔드 구성
- `api/db.ts`
  - Turso DB 초기화 및 `@libsql/client/web`을 활용한 공통 DB 연결 유틸리티
- `api/posts.ts`
  - 게시글 CRUD 및 검색/페이징 연산을 처리하는 API 엔드포인트
- `api/middleware/initDb.ts`
  - 서버리스 환경의 콜드 스타트 시, 초기 테이블 구조 생성 및 DB 정합성을 보장하는 미들웨어 (Sync Lock 적용)

## 4. API 설계 예제
### 4-1. 게시글 목록 조회 및 검색
- HTTP 메서드: `GET`
- 경로: `/api/posts`
- 설명: 등록된 게시글 목록을 페이징 처리 및 검색 키워드에 따라 필터링하여 반환
- 쿼리 파라미터:
  - `page`: 조회할 페이지 번호 (기본값: 1)
  - `limit`: 한 페이지당 출력할 글 개수 (기본값: 10)
  - `search`: 제목 또는 내용 검색 키워드 (선택)

### 4-2. 게시글 상세 조회
- HTTP 메서드: `GET`
- 경로: `/api/posts/:id`
- 설명: 특정 게시글의 상세 정보 반환 및 조회수 1 증가 처리

### 4-3. 게시글 등록
- HTTP 메서드: `POST`
- 경로: `/api/posts`
- 설명: 새 게시글 등록
- 요청 본문 예시:
  ```json
  {
    "title": "안티그래비티와 함께하는 바이브 코딩 입문",
    "author": "홍길동",
    "content": "Vite + Vue 3 환경에서 Vanilla CSS와 함께 고품격 게시판을 만들어 봅니다.",
    "category": "자유"
  }
  ```

### 4-4. 게시글 수정
- HTTP 메서드: `PUT`
- 경로: `/api/posts/:id`
- 설명: 기존 등록된 게시글의 제목, 내용, 카테고리 정보 수정

### 4-5. 게시글 삭제
- HTTP 메서드: `DELETE`
- 경로: `/api/posts/:id`
- 설명: 특정 게시글 영구 삭제

## 5. 게시판 아키텍처 노트
### 5-1. 데이터 모델 예시 (SQLite / Turso DB)
- `posts` 테이블 필드
  - `id`: `INTEGER PRIMARY KEY AUTOINCREMENT` (자동 증가 번호)
  - `title`: `TEXT NOT NULL` (게시글 제목)
  - `author`: `TEXT NOT NULL` (작성자)
  - `content`: `TEXT NOT NULL` (본문 내용)
  - `category`: `TEXT` (게시글 카테고리)
  - `views`: `INTEGER DEFAULT 0` (조회수)
  - `createdAt`: `DATETIME DEFAULT CURRENT_TIMESTAMP` (등록 일시)
  - `updatedAt`: `DATETIME DEFAULT CURRENT_TIMESTAMP` (수정 일시)

### 5-2. 서버리스 환경 고려 사항
- Vercel Serverless Functions는 인스턴스가 자주 실행되고 소멸(Cold Start)할 수 있으므로, 단일 연결 풀 유지 대신 `@libsql/client/web` 드라이버를 통해 HTTP API 방식으로 빠르게 쿼리를 수행합니다.
- Node.js ESM 환경 규격을 따르기 위해 모든 내부 모듈 임포트 시 반드시 `.js` 확장자를 명시합니다.
  ```typescript
  import { db } from './db.js';
  ```

### 5-3. 동기화 보장 미들웨어 (Sync Lock)
- 서버 인스턴스 기동 시 최초 한 번만 데이터베이스 테이블 생성이 수행되도록 잠금(Lock) 메커니즘을 두어 동시성 쿼리 충돌을 완벽히 방어합니다.

## 6. 일반 게시판 실습 흐름
1. **환경 설정**: `doc/개발환경.md`를 참고하여 Turso DB 토큰 및 Vercel 로컬 환경 변수 세팅
2. **테이블 설계**: `posts` 테이블을 생성하고 기본 더미 데이터를 삽입하는 데이터베이스 마이그레이션 스크립트 작성
3. **백엔드 API 구현**: `api/posts.ts` 파일에 Express 라우터를 작성하고 CRUD 쿼리문 연결
4. **프론트엔드 목록 구현**: Vue 3 Composition API를 활용해 `BoardList.vue` 화면에 쿼리 스트링 기반 페이징과 검색창 구현
5. **상세 및 쓰기 화면 연동**: `BoardDetail.vue` 및 `BoardWrite.vue` 컴포넌트의 폼 상태 관리 및 API 통신 기능 추가
6. **디자인 입히기**: Vanilla CSS로 모던 다크모드, 글래스모피즘(Glassmorphism) 효과 등이 적용된 프리미엄 UI 디자인 설계
7. **배포 및 검증**: Vercel에 배포하여 모바일 및 데스크톱 환경에서 오작동 없는 동작 여부 최종 검증

## 7. 참고 사항
- 실제 운영 환경으로 고도화 시, 게시글 수정/삭제 시 필요한 **비밀번호 인증** 또는 **JWT 기반 회원 인증 미들웨어** 추가가 권장됩니다.
- 본 가이드는 `doc/개발내용-예제.md` 아키텍처 포맷과 완전한 대칭성을 지니므로 병렬 학습이 수월합니다.
