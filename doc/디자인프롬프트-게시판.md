# 일반 게시판 디자인프롬프트 가이드

이 문서는 일반 게시판 서비스(`c:\github.com\myproject1\doc\개발내용-게시판.md` 참조)의 프론트엔드를 개발하거나 디자인 생성 AI(Antigravity 등)에 UI 설계를 지시할 때 사용하는 **고품격 프리미엄 UI/UX 디자인 시스템 및 스타일 프롬프트 명세**입니다.

---

## 🎨 1. 디자인 키워드 & 컨셉
- **키워드**: `Futuristic`, `Sleek`, `Glassmorphism`, `Minimalistic`, `Interactive`
- **컨셉**: 깊이감 있는 세련된 다크 테마를 기반으로 한 유리 형태의 반투명 효과(글래스모피즘)를 적용하고, 네온 질감의 Harmonious Accent Color 및 미세 애니메이션을 더해 사용자가 첫눈에 감탄할 수 있는 프리미엄 피니시를 구현합니다.

## 🔒 2. 디자인 시스템 토큰 (CSS 변수)
디자인의 일관성을 확보하고 ad-hoc 유틸리티 남용을 예방하기 위해 아래의 CSS 표준 변수 체계를 필수적으로 적용합니다.

```css
:root {
  /* Harmonious Slate Dark Palette */
  --bg-primary: hsl(220, 24%, 7%);       /* 배경: 심해색에 가까운 딥슬레이트 */
  --bg-secondary: hsl(222, 20%, 12%);    /* 서브배경: 살짝 밝은 네이비 다크 */
  --bg-glass: hsla(222, 20%, 12%, 0.6);   /* 글래스모피즘용 반투명 배경 */
  --border-glass: hsla(0, 0%, 100%, 0.08);/* 글래스모피즘용 미세 흰색 테두리 */
  
  /* Text System (Outfit, Inter 폰트 최적화) */
  --text-primary: hsl(210, 40%, 98%);     /* 주 텍스트: 완전 백색에 가까운 블루화이트 */
  --text-secondary: hsl(215, 16%, 70%);   /* 부 텍스트: 은회색 */
  --text-muted: hsl(215, 12%, 50%);       /* 캡션/정보: 뮤트 그레이 */

  /* Harmonious HSL Accent Colors */
  --accent-blue: hsl(224, 100%, 65%);     /* 주 액센트: 전기적인 느낌의 라이트블루 */
  --accent-purple: hsl(263, 90%, 65%);   /* 부 액센트: 신비로운 바이올렛 */
  --accent-emerald: hsl(150, 80%, 55%);  /* 성공/조회: 산뜻한 에메랄드 */
  --accent-rose: hsl(340, 85%, 60%);     /* 경고/삭제: 고급스러운 로즈핑크 */
  
  /* Glassmorphism Shadows & Blur */
  --blur-amount: 16px;
  --shadow-premium: 0 8px 32px 0 rgba(0, 0, 0, 0.37);
  --radius-lg: 16px;
  --radius-md: 10px;
  --transition-smooth: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);
}
```

## 💻 3. 컴포넌트별 디자인 프롬프트 & 스타일 명세

### 3-1. 공통 레이아웃 (Glassmorphism Wrapper)
- **프롬프트 가이드**:
  > "컨테이너 카드는 반투명한 화이트 테두리(`border: 1px solid var(--border-glass)`)를 가지고, 내부에는 은은하게 뒤쪽 배경 이미지를 통과시키는 `backdrop-filter: blur(var(--blur-amount))` 속성을 적용합니다. 카드 하단에는 부드러운 다크 섀도우를 깔아 공중에 뜬 듯한 극도의 입체감을 부여합니다."
- **추천 CSS**:
  ```css
  .glass-card {
    background: var(--bg-glass);
    backdrop-filter: blur(var(--blur-amount));
    -webkit-backdrop-filter: blur(var(--blur-amount));
    border: 1px solid var(--border-glass);
    border-radius: var(--radius-lg);
    box-shadow: var(--shadow-premium);
  }
  ```

### 3-2. BoardList.vue (게시판 목록 화면)
- **프롬프트 가이드**:
  > "게시판 테이블은 빽빽한 일반 격자형 테이블 스타일을 버리고, 각 게시글 행(Row)이 개별적인 얇은 카드로 동작하도록 여백을 넉넉히 설계합니다. 마우스 호버 시 카드 전체가 부드럽게 밝아지며 오른쪽 상단으로 `2px` 이동(`transform: translateY(-2px)`)하고 액센트 블루 색상의 미세한 네온 광(Outer Glow)이 테두리에 피어오르도록 트랜지션을 적용합니다."
  - **검색창**: 입력 창에 포커스가 갈 때, 테두리가 단순 선이 아니라 `accent-blue`와 `accent-purple`이 혼합된 듀얼 그라데이션 선으로 확장되는 인터랙티브 효과를 부여합니다.
  - **페이징 네비게이션**: 숫자는 단순 박스가 아닌 동글동글한 글래스 칩 형태로 디자인하고, 현재 활성화된 페이지는 `linear-gradient` 그라데이션이 채워진 채 네온 빛을 내는 형태로 구현합니다.

### 3-3. BoardDetail.vue (게시글 상세 보기 화면)
- **프롬프트 가이드**:
  > "상세 본문은 잡지 레이아웃처럼 와이드하고 시원하게 배치합니다. 글 제목은 그라데이션 타이포(`background-clip: text`)를 사용하여 가독성과 고급스러움을 극대화하고, 작성자 정보와 작성일 등의 메타데이터는 작고 세련된 실버 배지 형태로 정렬합니다. 본문 영역은 다크 테마에서 눈에 피로를 주지 않는 연회색 텍스트와 풍부한 라인 하이트(`line-height: 1.7`)를 적용합니다."
  - **액션 버튼(목록, 수정, 삭제)**: 수정 버튼은 블루 그라데이션으로, 삭제 버튼은 깊이감 있는 덜(Dull)한 로즈 톤에서 호버 시 매혹적으로 활성화되는 로즈 핑크(Neon Rose) 톤으로 변화하며 스케일이 `1.03`배 미세하게 커지는 햅틱 애니메이션을 부여합니다.

### 3-4. BoardWrite.vue (게시글 작성 폼 화면)
- **프롬프트 가이드**:
  > "입력 폼은 필드 라벨이 상단에 은은하게 떠 있고, 인풋에 글자가 타이핑될 때 라벨의 색상이 액센트 보라색으로 변하며 위쪽으로 미세하게 슬라이드되는 애니메이션을 적용합니다. 텍스트 에어리어는 크기 조절이 유연하며, 포커스 상태에서 부드러운 네이비 그로우 효과를 유지합니다."

## ⚡ 4. 마이크로 애니메이션 & 호버 효과 규칙
1. **버튼 스케일 피드백**: 모든 클릭 가능 요소는 활성 상태(`:active`)에서 `scale(0.96)`, 호버 상태(`:hover`)에서 `scale(1.02)`을 유지하여 반응형 햅틱 느낌을 줍니다.
2. **리플렉트 효과 (Shimmer Effect)**: 버튼이나 중요 카드 컴포넌트에 마우스를 올리면 반짝이는 빛 한 줄기가 왼쪽에서 오른쪽으로 빠르게 훑고 지나가는 그라데이션 리플렉션 애니메이션을 적용해 생동감을 더합니다.
3. **스무스 이징**: 모든 애니메이션에는 둔탁한 `linear` 대신 부드러운 가속과 감속이 들어간 `cubic-bezier(0.4, 0, 0.2, 1)` 트랜지션을 적극 차용합니다.

## 🎨 5. 디자인 프롬프트 가이드 (AI 템플릿용 한글 지시어)
"AI 코더에게 본 게시판을 스타일링하도록 명명할 때 아래 프롬프트를 복사하여 그대로 적용하십시오."

> **"Vite + Vue 3 일반 게시판 스타일링 프롬프트"**
> 
> "이 게시판은 프리미엄 글래스모피즘(Glassmorphism)과 퓨처리틱 슬레이트 다크 테마를 완벽히 융합하여 구현해 줘. 
> 1. 전체 배경은 `#0e1117` 수준의 딥 다크 톤으로 하고, 컨테이너 요소는 `backdrop-filter: blur(16px)`와 `rgba(255,255,255,0.06)`의 은은한 반투명 보더 테두리를 가진 화이트-유리 카드로 구성해 줘.
> 2. 타이포그래피는 구글 폰트 `Outfit`을 주 제목에, `Inter`를 본문에 적용하여 고해상도 맥북 Retina 디스플레이에서도 극강의 세련됨을 전달하도록 서체 렌더링을 튜닝해 줘.
> 3. 목록의 각 게시글 행(Row)은 단순 선이 아니라 호버 시 `translateY(-2px)` 되며 은은한 인디고 보랏빛 아우터 글로우(`box-shadow`)가 살아나는 유려한 인터랙티브 효과를 적용해 줘.
> 4. 모든 애니메이션은 `transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1)` 로 조율해서 브라우저 스크롤 및 포커스가 물 흐르듯 유연하게 움직이도록 만들어 줘."
